# Markspace 开发需求文档 (PRD)

## 1. 项目概述

Markspace 是一款轻量级、隐私优先的边缘响应式 Markdown 笔记应用。项目基于 Cloudflare 边缘生态构建，结合基于信封加密（Envelope Encryption）的端到端加密（E2EE）架构与丰富的数据扩展能力，旨在为用户提供快速、安全且具备轻量表格计算、多媒体处理能力与极简美学的笔记体验。

## 2. 核心架构与技术选型

* **前端框架**：React + TypeScript + Tailwind CSS
* **界面组件库**：shadcn-ui
* **设计风格**：Swiss Style (瑞士平面设计风格) + Apple 风格玻璃拟态 (Glassmorphic)
* **边缘服务端**：Cloudflare Workers + Cloudflare Pages
* **数据存储**：
  * **元数据/索引/结构化数据**：Cloudflare D1 (Relational Database)
  * **加密笔记实体/媒体文件**：Cloudflare R2 (Object Storage)
  * **实时协作与协同锁（可选）**：Cloudflare Durable Objects
* **加密库**：Web Cryptography API (SubtleCrypto)
* **Markdown 解析引擎**：Remark / Rehype 生态体系

## 4. 核心功能需求

### 4.1 端到端信封加密 (Envelope Encryption E2EE)

为保障极致的数据安全与密钥管理灵活性，系统全面采用**信封加密架构**。密文数据与加密密钥分离，所有加解密过程严格限定在客户端浏览器内存中完成。


```

[用户主密码 Master Password]
│ (PBKDF2 / Argon2id)
▼
[客户主密钥 CMK (Customer Master Key)]  <── 仅存于客户端内存
│
│ (使用 AES-GCM-256 加密 / 解密)
▼
[数据加密密钥 DEK (Data Encryption Key)] <── 明文仅存于客户端内存 / 密文存入服务端
│
│ (使用 AES-GCM-256 加密 / 解密)
▼
[笔记文本 / 媒体文件Payload]              <── 密文存入 Cloudflare R2 / D1

```

* **密钥层级定义**：
  * **客户主密钥 (CMK, Customer Master Key)**：
    * 派生机制：在客户端由用户输入的**主密码 (Master Password)** 配合随机 Salt，通过 `PBKDF2` (或 `Argon2id`) 派生生成。
    * 作用：仅用于对数据加密密钥 (DEK) 进行封套加密 (Wrap) 与解封 (Unwrap)。
    * 存储规范：**严禁上传或持久化**。仅在当前会话激活期间存在于客户端内存中。
  * **数据加密密钥 (DEK, Data Encryption Key)**：
    * 生成机制：由客户端 `SubtleCrypto.generateKey()` 动态生成的随机 `AES-GCM-256` 密钥。每个独立实体（如单篇笔记、单个媒体文件）均分配独立的 DEK。
    * 作用：直接对笔记主体内容及多媒体数据流进行明文对称加密。
    * 存储规范：DEK 被 CMK 加密后生成 `Encrypted_DEK`，随笔记/文件的加密元数据一同持久化存储于 Cloudflare D1 或 R2。
* **加密流程 (Envelope Encryption)**：
  1. 客户端生成新的随机 DEK。
  2. 使用 DEK 结合随机 IV 对笔记或媒体 Payload 进行 `AES-GCM-256` 加密。
  3. 使用内存中的 CMK 对 DEK 进行加密，得到 `Encrypted_DEK`。
  4. 将加密后的 Payload 及 `Encrypted_DEK` 上传至 Cloudflare Workers 存入 R2/D1。
* **解密流程 (Envelope Decryption)**：
  1. 客户端从服务端获取 `Encrypted_DEK` 及加密 Payload。
  2. 客户端使用内存中的 CMK 解封 `Encrypted_DEK`，还原出明文 DEK。
  3. 客户端使用解封后的 DEK 解密 Payload，在界面中渲染呈现。

### 4.2 Markdown & HTML 解析引擎

* **基础语法**：完整支持 CommonMark 与 GFM (GitHub Flavored Markdown) 标准。
* **HTML 元素支持**：
  * 支持解析与渲染安全范围内的原生 HTML 标签（如 `details`, `summary`, `kbd`, `mark`, `div` 等）。
  * **安全防御**：嵌入 `DOMPurify` 或 Rehype 安全插件，强制过滤 `script` 标签、内联事件句柄（如 `onload`, `onclick`）及潜在的 XSS 攻击向量。

### 4.3 增强型表格计算 (Sheet Functions)

支持在 Markdown 表格中嵌入类似 Google Sheets 的计算公式，提升数据整理能力。

* **语法设计**：
  * 支持在表格单元格中使用公式前缀，例如 `=SUM(A1:A5)`、`=AVERAGE(B1:B10)`、`=COUNT(C1:C5)`。
  * 支持基本的跨行列计算及四则运算（`+`, `-`, `*`, `/`）。
* **内置函数库**：
  * `SUM`：行/列或区域求和。
  * `AVERAGE` / `AVG`：计算平均值。
  * `COUNT` / `COUNTA`：统计数值或非空单元格数量。
  * `MIN` / `MAX`：取极值。
* **解析与渲染**：
  * 扩展 Markdown 解析器，在 AST 节点层级识别表格与公式表达式。
  * 渲染时动态计算依赖关系并输出计算结果，同时保留原始公式以便二次编辑。

### 4.4 多媒体嵌入与渲染

* **媒体类型支持**：
  * **图片**：支持常见格式（PNG, JPEG, WebP, GIF, SVG），提供放大预览、外框尺寸调节与延迟加载（Lazy Loading）。
  * **音频**：内置自定义 HTML5 音频播放器，支持 MP3, WAV, OGG, AAC。
  * **视频**：支持 MP4, WebM 视频播放，以及第三方视频（如 YouTube, Bilibili）的 iframe 安全嵌入。
* **媒体存储与流式解密**：
  * 上传媒体文件前在客户端利用独立 DEK 完成加密，通过 Cloudflare Workers 直传至 R2。
  * 媒体加载时通过 Service Worker 拦截媒体请求，从 R2 拉取密文流并在客户端实时解密为 Blob URL 供播放器渲染。

## 5. API 与边缘服务设计 (Cloudflare Workers)

### 5.1 认证与鉴权

* `POST /api/v1/auth/register`：注册账号（提交主密码派生的认证 Token，非 CMK 或主密码本身）。
* `POST /api/v1/auth/login`：登录鉴权，返回 JWT/Session Cookie。

### 5.2 笔记管理

* `GET /api/v1/notes`：获取笔记元数据列表（包含 `id`, `Encrypted_Title`, `Encrypted_DEK`, `created_at` 等）。
* `POST /api/v1/notes`：新建笔记（上传加密后的文本 Payload 与被 CMK 加密的 `Encrypted_DEK`）。
* `GET /api/v1/notes/:id`：获取单篇加密笔记内容及对应的 `Encrypted_DEK`。
* `PUT /api/v1/notes/:id`：更新笔记。
* `DELETE /api/v1/notes/:id`：删除笔记（同时级联清理 R2 关联资源）。

### 5.3 媒体资源接口

* `POST /api/v1/media/upload-url`：获取 R2 加密上传预签名地址及存储元数据。
* `GET /api/v1/media/:id`：获取加密媒体文件流及关联的 `Encrypted_DEK`。

## 6. 非功能性需求

* **性能**：利用 Cloudflare 边缘网络，静态资源全球 CDN 加速，API 响应时间（TTFB）保持在 50ms 以内（不含网络传输延迟）。
* **视觉与体验**：高斯模糊渲染流畅，暗色/亮色模式切换顺滑无闪烁，悬浮面板无卡顿。
* **安全性**：
  * 采用信封加密机制，即使数据库与 R2 存储全面泄露，在缺乏 CMK 的情况下也无法解开任何一个 DEK 或文件数据。
  * 强制全局 HTTPS (TLS 1.3)。
  * 严格配置 CSP (Content Security Policy)，限制不信任的外部资源加载。
* **可靠性与扩展性**：基于 D1 与 R2 的分布式存储架构，保证 99.9% 以上的数据可用性。

## 7. 项目里程碑规划

1. **第一阶段 (MVP & E2EE 架构)**：搭建 Cloudflare Worker 边缘服务端，实现基于 shadcn-ui + 悬浮玻璃面板的视觉框架；完成 CMK/DEK 信封加密体系与笔记 CRUD。
2. **第二阶段 (渲染与多媒体扩展)**：集成 Markdown + HTML 解析器，实现安全过滤机制与加密媒体文件的流式上传与解密播放。
3. **第三阶段 (表格计算引擎)**：开发 Markdown AST 扩展，实现表格单元格坐标解析与 Google Sheets 核心函数计算。
4. **第四阶段 (主题优化与发布)**：精细化暗色/亮色主题切换、打磨 Apple 风格玻璃拟态交互细节、完成 PWA 离线支持与安全审计。
